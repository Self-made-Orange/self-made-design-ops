## 한 줄 요약

Audi 브랜드 웹 UI — **모듈러 스케일의 비율이 뷰포트 급에 따라 커지는**
(1.14→1.25) 유일 표본이고, 전역 이징이 **단 1개**이며, 색이 사실상
**무채색 램프 + 브랜드 레드**뿐입니다. 자동차 **브랜드 웹**이라
Android Automotive·CarPlay(차내 HMI)와는 다른 축입니다.

## 타이포 — 뷰포트별 모듈러 스케일 비율

```scss
$aui-modular-scale: (
  default: ( base: 16px, ratio: 1.14 ),
  small:   (            ratio: 1.17 ),
  large:   ( base: 18px, ratio: 1.21 ),
  huge:    ( base: 20px, ratio: 1.25 ),
);
```

**화면이 클수록 base도 ratio도 커집니다** — 16px/1.14에서 20px/1.25까지.
코퍼스의 모듈러 스케일 표본(Odyssey 등)은 비율이 고정인데, Audi는
**비율 자체가 반응형**입니다. 큰 화면에서 위계 대비가 더 벌어집니다.

## 모션 — 전역 이징 1개

```scss
$aui-easing: cubic-bezier(0.75, 0.02, 0.5, 1);
```

이징 토큰이 **하나뿐**입니다 (방향·강도 분화 없음). x1=0.75로 늦게 출발해
중반에 몰아치는 곡선 — Material Legacy(0.4, 0, 0.2, 1)보다 훨씬 극적입니다.
필드 전환은 0.25s.

## 색 — 무채색 브랜드

- 유채색: **red `#bb0a30`(브랜드) · yellow · green** — 상태색 겸용 3개가 전부
- 무채색: `gray10~gray95` **11단계** + black/white — 숫자가 밝기 %에 대응
  (gray95 = `#f2f2f2`)
- Porsche와 같은 독일 자동차 브랜드 축이지만 Porsche는 `light-dark()` 같은
  최신 CSS를 쓰고, Audi는 2019년대 SCSS 변수 체계입니다(1.0.0-alpha.2에서 정지)

## 그 외 수치

| 항목 | 값 |
|------|-----|
| 베이스 단위 | 4px (`$aui-base-unit`), rem 루트 16px |
| 필드 높이 | `unit(10)` = 40px |
| 아이콘 | 24/48px + **"system" 변형 23/45px** (스트로크 1.1px) |
| 그리드 | 12열, 거터 unit(1), 컨테이너 오프셋 **4.375%** |
| 브레이크포인트 | 7단계 (480~1584px) |
| z-index | header 100 · dropdown 1000 — 2개뿐 |

- `$aui-circle-smoothing-factor: 2` — **Chrome 서브픽셀에서 원을 2배로 그려
  줄이는 스무딩 계수**가 변수로 있습니다. 렌더링 버그 대응이 토큰 층에
  올라온 드문 사례.
- 컴포넌트 53종 디렉터리, 각각 `*-themes.scss` 분리 — 테마가 컴포넌트별
  파일로 쪼개진 구조.
- 서체 `AudiTypeScreen`/`AudiTypeExtended` — display 전용 Extended 분리
  (Asphalt의 Extended 분리와 같은 유형).

## 컴포넌트 심화 — (2026-08-18)

**2017-11 동결 스냅샷 기준입니다** — `@audi/audi-ui@1.0.0-alpha.2`가 npm 최종
배포이고 저장소는 삭제됐으므로, 아래 값은 역사 표본이지 현행 Audi 규격이 아닙니다.
소스 SCSS와 함께 **동봉된 컴파일 산출물 `dist/audi-ui.css`로 실값을 검증**했습니다.

### 버튼 — 백로그 해소: 실효 높이 51px, 그리고 그 높이가 반응형입니다

컴파일 CSS의 실제 선언:

```css
html { font-size: 16px; }                 /* ≥1264px: 18px · ≥1584px: 20px */
.aui-button {
  font-size: 0.9375rem;                   /* 15px @ 루트16 */
  line-height: 1.5rem;                    /* 24px */
  padding: 0.8666666667em 0 0.8em;        /* 13px / 12px @ 폰트15 */
  border: 1px solid transparent;
}
```

| 뷰포트 | 루트 | 버튼 서체 | 실효 높이 (행간+패딩+보더) |
|--------|:---:|:---:|:---:|
| 기본 | 16px | 15px | **51px** (24+13+12+2) |
| ≥1264px | 18px | 16.875px | **≈57.1px** |
| ≥1584px | 20px | 18.75px | **≈63.3px** |

- ~~em 기반 패딩이라 서체 크기 의존~~ — 확정: 서체·행간이 rem, 패딩이 em이라
  **루트 폰트(16→18→20px)를 따라 버튼 높이 자체가 51→57→63px로 커집니다.**
  뷰포트별 모듈러 스케일(위 타이포 절)이 컴포넌트 치수까지 관통하는 구조로,
  고정 px 높이 진영 전체와 다른 층입니다.
- **상하 패딩이 13/12px 비대칭**입니다 — 위가 1px 더 큽니다 (서체 광학 보정 흔적).
- **기본 변형이 텍스트 버튼입니다** — 투명 배경·투명 보더·**좌우 패딩 0**.
  `--primary`(검정 채움)·`--secondary`(보더)가 붙어야 좌우 패딩 32px(= 루트×2,
  이것도 반응형 36/40px)이 생깁니다. 채움 버튼이 기본인 표본 다수와 대극.
- **라운드 0** — 직각. 브랜드 레드가 아니라 **검정이 버튼 색**입니다.
- disabled가 opacity 0.30 — Astro·Atlassian의 40%보다 더 낮습니다.

### 텍스트필드 — 밑줄형 + 플로팅 라벨

| 항목 | 값 |
|------|-----|
| 형태 | **밑줄만** (`border-bottom` 1px rgba(0,0,0,.3)) — 배경·상자 없음 |
| min-height | `unit(10)` = 2.5rem = **40px @루트16** (→ 45/50px 반응형) |
| 라벨 | **플로팅** — 위로 떠서 0.75rem(12px)로 축소 |
| 상태 | hover/focus/dirty 전부 rgba(0,0,0,.8) — **색 대신 불투명도 램프** |
| 전환 | 0.25s, 전역 이징 |

- 보더·배경 없는 밑줄 필드는 Material 1세대(2017) 관행과 동시대입니다 —
  MUI의 `standard` 변형과 같은 형태가 기본입니다.
- 상태 표현이 색상 변화가 아니라 **검정의 알파 램프**(.3→.8)입니다 —
  무채색 브랜드 원칙이 필드 상태에도 적용된 형태.

### 모달 — 오버레이가 아니라 표면 교체

| 항목 | 값 |
|------|-----|
| 기본형 | **다이얼로그 자체가 100vh · `#333333`(gray20) 전면** — 스크림+카드 아님 |
| 본문 폭 | ≥600px에서 **62.5%**, max **1200px** |
| 변형 | fullpage / window(80%, 투명 배경 위 다크 패널) / layer(translateY 10px 진입) |
| 전환 | 페이드 **0.4s + 지연 0.4s** (morph 변형만 지연 0) — 전역 이징 |
| 닫기 버튼 | **45px → 81px**(≥600px) — 주석에 "sync with JS" |

- **모달이 밝은 페이지 위의 어두운 전면 표면입니다** — 배경 흐림·스크림 진영
  전체와 다른, 화면을 통째로 바꾸는 브랜드 연출입니다.
- 지연 0.4s는 배경 전환이 끝난 뒤 내용을 띄우는 2단 안무 — 총 0.8s로
  표본 모달 중 가장 느립니다 (Astro 0.5s보다도).
- 닫기 45/81px처럼 **JS와 값 동기화를 주석으로 관리** — 토큰 이전 세대의
  수작업 계약이 그대로 보존돼 있습니다.

### 특징적 결정 (심화분)

- **버튼 실효 높이가 반응형** (51→57→63px) — em/rem 이중 스케일이 치수까지 관통
- **기본 버튼 = 텍스트형·좌우 패딩 0** — 채움이 수식어
- **라운드 0 전면** + 상태를 알파 램프로 — 무채색·직각의 브랜드 극단
- **모달 = 표면 교체** (100vh 다크) + 0.4s+0.4s 2단 안무
- 상하 패딩 13/12 비대칭 — 1px 광학 보정

## 특징적 결정

- **뷰포트별 모듈러 스케일 비율** (1.14→1.25) — 코퍼스 유일
- 전역 이징 1개 — 최소주의 모션의 극단
- 무채색 램프 11단계 + 브랜드 레드 — 자동차 브랜드 모노톤
- 아이콘 정수/비정수 쌍(24/23, 48/45) — 광학 보정 흔적
- alpha에서 개발 정지 (1.0.0-alpha.2, Apache-2.0)
