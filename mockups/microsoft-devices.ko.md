# Microsoft 공식 디바이스 목업 — 없음 확인

**Microsoft는 Surface 등 자사 하드웨어의 공식 목업을 공개 배포하지 않습니다.**

확인한 경로:

- **Figma 공식 계정 @microsoft** — Windows UI Kit, Microsoft 365 UI Kit, Fluent
  킷·플러그인 30여 종을 발행하지만 **하드웨어 목업은 없음**
  ([`figma-community-kits.md`](figma-community-kits.md) 참고).
- **웹 검색** — "Surface mockup PSD"로 잡히는 것은 전부 서드파티
  (unblast, psdrepo, Anthony Boyd 등). 공식 배포 채널 없음.
- Microsoft 브랜드 사이트는 로고·상표 가이드라인만 다룹니다.

## 미확인

- Microsoft Partner Center에 파트너 전용 마케팅 에셋이 있을 가능성 —
  로그인 필요라 **미확인**.
- 프레스용 제품 사진은 news.microsoft.com 이미지 갤러리에 있으나 보도 용도.

## 대안

Surface 목업이 필요하면:

- **Meta Devices** ([`meta-devices.md`](meta-devices.md)) — Surface 3 · Surface
  Pro 4 · Surface Pro X · Surface Book · Lumia 950 포함. 단 비상업 용도 한정.
- 그 외는 서드파티 킷 — 라이선스 개별 확인 필요.
