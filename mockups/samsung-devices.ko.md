# Samsung 공식 디바이스 에셋 — 인벤토리

**Samsung은 디자인·마케팅용 목업 킷을 제공하지 않습니다 (없음 확인).**
공식으로 받을 수 있는 기기 외형 에셋은 **Galaxy Emulator Skin** 하나뿐입니다 —
Android Studio 에뮬레이터에 Galaxy 기기 외형을 씌우는 스킨(zip)입니다.

- URL: <https://developer.samsung.com/galaxy-emulator-skin>
- 형식: zip (에뮬레이터 스킨 규격 — PNG 레이어 + layout 파일)
- 용도: 개발·테스트. 시안용 목업으로 쓰려면 PNG 레이어를 꺼내 쓰는 편법이 되는데,
  마케팅 사용을 허용한다는 문구는 어디에도 없습니다.

## 커버 기기

Apple 킷들과 달리 **최신 기기까지 따라옵니다.** 확인 시점의 Featured 목록:

Galaxy Z Fold8 Ultra · Z Fold8 · Z Flip8 · S26 Ultra · S26+ · S26 ·
**Z TriFold** · Tab S11 Ultra

카테고리별 페이지 (각각 세대별 스킨 제공):

| 카테고리 | 확인한 범위 |
|----------|-------------|
| Galaxy S | S10 시리즈 ~ S26 시리즈 (FE·Edge·Ultra 변형 포함) |
| Galaxy Z | Z Flip ~ Z Flip8 (Flip7 FE 포함) · Z Fold(구 Galaxy Fold) ~ Z Fold8 Ultra · Z TriFold |
| Galaxy A | 별도 페이지 있음 (기기 목록 미확인) |
| Galaxy Tab | 별도 페이지 있음 — Tab S11 Ultra까지 확인 |
| Galaxy Note | 별도 페이지 있음 (단종 라인, 아카이브성) |

아카이브 페이지(`/archive.html`)와 릴리스 노트도 별도로 있습니다.

## 없음 / 미확인

- **디자인용 목업 킷(PSD·Sketch·Figma) 없음 확인** — developer.samsung.com과
  Figma를 뒤져도 하드웨어 목업 배포가 없습니다.
- **Figma 공식 계정 @samsung은 존재하지만 리소스 0개** (2026-08-18 확인).
- 프레스용 제품 이미지는 Samsung Newsroom에 있으나 보도 용도라 시안·마케팅
  사용 조건은 **미확인**.

## 쓸 때 주의

- 에뮬레이터 스킨은 **정면 뷰 1종**입니다. 색상 변형·측면 뷰 같은 건 없습니다.
- Galaxy 기기 목업이 필요한 시안 작업은 사실상 서드파티 킷(예: Meta Devices의
  Galaxy 구형 모델)이나 커뮤니티 파일에 의존해야 합니다.
